## Project 4
This project demonstrates the use of ros2 and moveit2 for a pick and place task with a 7 dof robot arm.

### Overview
This repository is for the project files created by the moveit setup assistant as well as the code to run the program task. 
The project folder is called "joseph_project4" and the main package inside it called "new_package".

### Dependencies
ros2
moveit2
ubuntu 22.04 humble
The entire folder of "joseph_project4"

### Run Instructions
After cloning the repository or downloading the folder "joseph_project4", cd into "joseph_project4" and run:
ros2 launch new_package pick_move.launch.py
to launch the ros2 pick and place program.

### Outputs
A window will appear to visualize the robot animation.
